# TurfEase
Team college project (Object Oriented Programming) built in Java. A desktop app for booking turfs and indoor courts in Malappuram. Customers register, sign in, see only free time slots with the price, and book. An admin manages all bookings, facilities and prices.
Features: Swing GUI with FlatLaf, salted PBKDF2 password hashing, data saved to files, packaged as a runnable JAR. OOP concepts used: encapsulation, inheritance, abstraction, polymorphism, enums, a custom exception and a factory method.
